## ⚡ Quick Start

Green Hell offers item spawning through its PC debug menu. A separate community mod also provides a dedicated item-spawner interface.

1. Back up your save before experimenting with debug features or mods.
2. For the debug menu, enable the game's debug mode using the documented `DEBUG` file method.
3. Load a save, press `F1` to open the item debug menu, select an item, and press `I` to spawn it.

A community item-spawner mod also documents an `F6` menu for searching items and selecting quantities. Its availability and compatibility depend on the installed mod and game version.
